Problema de negocio

La clasificación temprana de casos sospechosos puede ayudar a ordenar mejor la revisión clínica y mostrar cómo un modelo puede apoyar una tarea sensible cuando se presenta con contexto y advertencias claras.

Qué se analizó

Se utilizaron 30 variables clínicas del tumor, incluyendo radio, textura, perímetro, área, concavidad y simetría, para distinguir entre casos benignos y malignos.

Solución implementada

Se construyó un flujo con entrenamiento del modelo, API REST, frontend interactivo, contenedorización con Docker y automatización mediante GitHub Actions.

Resultados obtenidos

El proyecto alcanzó métricas sólidas de clasificación y dejó una experiencia reproducible para probar inferencia, visualizar artefactos y comunicar el comportamiento del modelo.

Qué problema resuelve

Aunque es un proyecto educativo y no reemplaza criterio médico, demuestra cómo estructurar una herramienta que apoye clasificación de casos a partir de variables clínicas con una interfaz accesible para exploración.

Por qué importa

En machine learning aplicado, el valor no está solo en entrenar el modelo, sino en mostrar cómo se expone, cómo se prueba y cómo se comunica su uso responsable.

Qué se analizó

  • Variables clínicas relacionadas con forma, tamaño y textura del tumor.
  • Ejemplos benignos y malignos para facilitar pruebas controladas.
  • Artefactos visuales como matriz de confusión, ROC y features relevantes.

Enfoque analítico

El proyecto no se limita a una predicción final. También busca dar visibilidad a cómo se comporta el modelo, qué variables pesan más y cómo se puede inspeccionar el flujo desde la capa técnica.

Qué solución se implementó

  • Script de entrenamiento para generar artefactos reutilizables.
  • API Flask con endpoints para salud, ejemplos e inferencia.
  • Frontend Streamlit con sliders y visualizaciones del modelo.
  • Docker Compose para ejecutar API y frontend en contenedores.
  • CI/CD para ejecutar pruebas automáticas en cambios a main.

Cómo se aplica en negocio

Más allá del caso médico, el proyecto sirve como ejemplo de cómo empaquetar un modelo sensible para que pueda consumirse como servicio, explicarse con soporte visual y mantenerse con prácticas reproducibles.
