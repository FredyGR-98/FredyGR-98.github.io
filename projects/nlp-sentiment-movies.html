Problema de negocio

Cuando el feedback está en texto libre, cuesta convertirlo en señales accionables. Este caso muestra cómo transformar opiniones dispersas en una clasificación útil para lectura rápida.

Qué se analizó

Se trabajó con reseñas IMDb para limpiar texto, tokenizar, vectorizar con TF-IDF y entrenar un clasificador binario entre reseñas positivas y negativas.

Solución implementada

Se construyó un flujo con entrenamiento, artefactos serializados, API Flask, frontend Streamlit, Docker Compose y automatización con GitHub Actions.

Resultados obtenidos

El modelo logró un desempeño consistente y dejó una ruta clara para usar NLP en una experiencia simple, replicable y fácil de explicar.

Qué problema resuelve

Clasificar reseñas permite pasar de miles de opiniones textuales a una lectura binaria que puede servir para seguimiento de experiencia, percepción de producto o triage inicial de feedback.

Por qué importa

El texto es una fuente de señal rica pero costosa de revisar manualmente. Un pipeline NLP bien presentado ayuda a convertirlo en información útil para análisis posterior o monitoreo rápido.

Qué se analizó

  • Limpieza y tokenización de reseñas textuales.
  • Vectorización TF-IDF para traducir texto a variables numéricas.
  • Balance entre clases positiva y negativa en el set evaluado.

Lectura analítica

El proyecto busca demostrar que NLP no tiene que quedarse en un notebook. También puede exponerse con una interfaz clara para que una persona pruebe ejemplos y entienda el comportamiento del clasificador.

Qué solución se implementó

  • Entrenamiento con Logistic Regression.
  • Vectorizador serializado para reproducir inferencia.
  • API Flask para clasificar nuevas reseñas.
  • Frontend Streamlit para interacción amigable.
  • Docker Compose y CI/CD para ejecución reproducible.

Cómo se aplica en negocio

La misma lógica puede adaptarse a reseñas de clientes, tickets, encuestas o comentarios abiertos donde interese una lectura rápida de tono o percepción general.
